# Neon Apex: AI Arrow Protocol 🚀

A high-performance, browser-based arcade reflex game combining classic arrow-clearing mechanics with real-time web AI and Machine Learning. Built natively using HTML5 Canvas, Tailwind CSS, MediaPipe, and Web Audio API.

---

### ✨ Key Features & AI Integrations

* **🖐️ Computer Vision Air Gestures:** Powered by **MediaPipe Hands**, players can control and clear incoming arrows in mid-air using real-time webcam hand-tracking.
* **⚡ Adaptive Difficulty Engine:** The game dynamically monitors player score and reaction speeds, scaling up difficulty tiers in real-time.
* **🛡️ Strategic Decoy Mechanics:** Introduces predictive red decoy elements that penalize lives if clashed with, requiring split-second decision-making.
* **🤖 Post-Game AI Coach Analytics:** Generates a comprehensive performance breakdown upon session termination—calculating average reflex latency (in milliseconds), accuracy percentage, and delivering an AI playstyle assessment.
* **🎵 Procedural Audio Engine:** Fully immersive retro-futuristic sound effects synthesized dynamically using the browser's native **Web Audio API**.
* **🎨 Cyberpunk UI/UX:** Styled with glassmorphism panels, glowing neon accents, and smooth particle explosion effects.

---

### 🛠️ Tech Stack
* **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6+)
* **Graphics/Rendering:** HTML5 Canvas API
* **AI / ML Frameworks:** MediaPipe Hands (Client-side Computer Vision)
* **Audio:** Web Audio API
